# 1. 这个问题在比什么

## 一句话

rectified flow 里预测干净动作 `x` 和预测速度 `v` **代数等价**，但在有限宽度、双流、**没有 skip** 的动作专家里，它们强迫网络承担的表征负担不同。

## 路径约定

```
z_t = (1 − t) ε + t x          t=0 纯噪声，t=1 干净动作
v*  = x − ε
```

由此立刻有

```
x = z_t + (1−t) v
ε = z_t − t v
```

所以只要网络无限宽、优化完美，`x`-pred、`v`-pred、`ε`-pred 描述的是同一个最优流。本仓库不讨论“谁信息更多”，而讨论：

> 有限容量网络为了表达这三种目标，需要记住多少噪声、多少动作结构、多少 partner 流信息。

## 为什么这和双流 arm–base 有关

干净动作 chunk 是真机/示教轨迹：关节平滑、双专家协调、本体 mask，都把它压到低维流形上。  
速度 `v = x − ε` 和噪声 `ε` 带着满维高斯。  
如果网络必须从 `z_t` 经过固定宽度残差流才能到达输出，那么：

- `v`-pred / `ε`-pred：输出与输入噪声高度相关，残差流里会留下大量“这一次抽到了什么噪声”；
- `x`-pred：目标在流形上，许多噪声方向可以被忽略，腾出的容量可以编码 partner 流。

少步 Euler 采样的第一步发生在 `t≈0`，恰好是两种约定差得最大的地方。这就是“平均训练 loss 打平、部署行为不同”的来源。

## 本仓库主张什么、不主张什么

主张（在本 toy 的部署设定下）：

- 干净动作低维，含噪声的目标不满秩终止；
- x-pred 的 Jacobian 有效秩更低，自身噪声 R² 更低，partner 动作 R² 更高；
- 优势集中在高噪声端；
- 少 NFE 时 off-manifold / 无效自由度泄漏更低。

不主张：

- x-pred 在任何宽度、任何任务上都更准；
- 58D/token 上平均 excess risk 更低（实验里 v 还略低）；
- partner R² 高 ⇒ 因果上更依赖 joint attention（那是 encoding 指标）。

## 和真实模型的对应

Toy 模仿的是双流 joint-attention 动作专家（manipulation 58D + body 22D，chunk 16，rectified flow）。它**不是**完整 VLA。真实数据的奇异谱和真实模型上的 x/v 消融需要另做，不能从本仓库外推成已证实。
